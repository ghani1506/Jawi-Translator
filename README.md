# Jawi Translator

**Dicipta oleh Ghani Ahmad** · © 2026 Ghani Ahmad. All rights reserved.

A Rumi-to-Jawi converter that runs entirely in the browser and works offline once opened.

## Features

- Live Rumi → Jawi conversion, written right to left
- Rule-based spelling (special letters چ ݢ ڤ ڠ ڽ ۏ, alif rules, final k as ق, hamzah, -nya / -lah / -kah, di- prefix, -an suffix, ٢ for reduplication)
- Built-in list of about 300 common words, Arabic loanwords, Brunei names and maths terms
- Words converted by rules are underlined in red, with a **Semak di KamusDBP** button to check them
- **Kamus saya**: your own corrections, saved in the browser, with CSV import and export
- Jawi letter keypad for phones without a Jawi keyboard
- Installable on phones (Add to Home Screen) and usable offline

## Deploy on GitHub Pages

1. Create a new repository on GitHub, for example `jawi-translator`.
2. Upload every file and the `icons` folder (**Add file → Upload files**), then **Commit changes**.
3. Go to **Settings → Pages**. Under **Source**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the app is live at `https://<your-username>.github.io/jawi-translator/`.

## Install on iPhone (offline)

1. Open the GitHub Pages link in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open it once while online. After that it works without internet.

On Android, open the link in Chrome and choose **Install app** or **Add to Home screen**.

## Updating the app

1. Upload the new `index.html`.
2. In `sw.js`, change `VERSION` (for example `jawi-v1` → `jawi-v2`) so phones download the new version.

## Note on accuracy

Jawi spellings generated by rules are suggestions. Check them against official references such as KamusDBP (Dewan Bahasa dan Pustaka). Words saved in *Kamus saya* stay only in the browser where they were added; use **Salin CSV** to back them up.
